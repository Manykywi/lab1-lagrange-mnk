# 1. Технічне завдання (ТЗ)

**Проєкт:** веб-застосунок «Апроксимація функцій: інтерполяція Лагранжа та МНК»
**Лабораторна робота № 1**, варіант № 6
**Виконавець:** Белеканич Максим Олександрович, група ІПЗ-1 (УжНУ, факультет ІТ)
**Мова / стек:** JavaScript (ES2020), HTML5 Canvas, CSS3. Без зовнішніх бібліотек і збірки.

## 1.1. Призначення та мета

Реалізувати програмний продукт, що за таблично заданими точками `{(xᵢ, yᵢ)}` будує
1. інтерполяційний поліном Лагранжа (з перевіркою формою Ньютона через таблицю поділених різниць);
2. поліноміальну апроксимацію методом найменших квадратів (МНК) ступеня `m`;

та візуалізує результати (графіки, залишки, анімація побудови) для наборів із **5, 10 та 20 точок**.

## 1.2. Вхідні дані (варіант 6)

| Набір | Точки |
|---|---|
| 5 точок (задано варіантом) | (1; 5.2), (2; 4.8), (3; 4.5), (4; 4.1), (5; 3.8) |
| 10 точок | перші 5 точок варіанта + x = 6…10 |
| 20 точок | перші 10 точок + x = 11…20 |

**Припущення A1.** У таблиці варіантів для № 6 задано лише 5 точок. Набори з 10 і 20 точок
сформовано як вкладені (5 ⊂ 10 ⊂ 20) за тією ж закономірністю: спадний майже лінійний тренд
`y ≈ 5.55 − 0.35·x` із невеликою похибкою вимірювання (±0.1). Перші п'ять точок збігаються з варіантом.
Значення зафіксовано в `src/datasets.js`.

Користувач також може ввести **власний набір** точок у формі (рядки «x y»).

## 1.3. Функціональні вимоги

| ID | Вимога |
|---|---|
| FR-1 | Вибір набору точок: 5 / 10 / 20 (варіант 6) або власний набір, введений у форму. |
| FR-2 | Побудова полінома Лагранжа `pₙ(x) = Σ yₖ·Lₖ(x)`; контроль формою Ньютона (таблиця поділених різниць відображається в інтерфейсі). |
| FR-3 | МНК-апроксимація поліномом ступеня `m ∈ {2, 3, 4}` (за замовчуванням 2): дизайн-матриця, розв'язок **QR-розкладом Householder** (нормальні рівняння не використовуються), розрахункові значення `ŷᵢ`, залишки `rᵢ = yᵢ − ŷᵢ`. |
| FR-4 | Графік: експериментальні точки, крива інтерполяції, крива МНК; окремий графік залишків (штрихи + маркери + підписана нульова лінія `r = 0`). |
| FR-5 | Перемикач режиму «Інтерполяція / МНК / Усі». |
| FR-6 | Анімація інтерполяції: покрокове додавання вузлів, плавне оновлення кривої, виділення активного вузла (колір/розмір). |
| FR-7 | Анімація МНК: поліном «виростає» від горизонтальної лінії до остаточної кривої, залишки поступово з'являються відрізками від (xᵢ, ŷᵢ) до (xᵢ, yᵢ). |
| FR-8 | **Автомасштабування осей X та Y**: програма сама обчислює min/max функції (кривих, вузлів, залишків) і підбирає межі так, щоб графік завжди був у видимій зоні (також під час анімації). |
| FR-9 | Обчислення та відображення для 5, 10 і 20 точок: усього **6 графіків** (3 — Лагранж, 3 — МНК); режим «Порівняння 5·10·20» показує всі шість одночасно. |
| FR-10 | Перемикання між наборами 5/10/20 для миттєвого порівняння результатів (кнопки; порівняльна таблиця метрик). |
| FR-11 | Таблиця метрик: макс. та середньоквадратична похибка, SSE, R², діапазон кривої Лагранжа. |
| FR-12 | Опція показу екстраполяції (поза інтервалом вузлів) для демонстрації ризиків. |

## 1.4. Вимоги до інтерфейсу (UI/UX)

- Адаптивне полотно (Canvas): змінюється разом з вікном, коректно для HiDPI-екранів.
- Осі з підписами та сіткою, «гарні» позначки (кратні 1, 2, 5·10ⁿ), легенда.
- Підказки при наведенні: координати курсору, значення кривих, для вузла — `y`, `p(x)`, `ŷ` та похибка `r` у точці.
- Контрастні кольори кривих (синій — Лагранж, помаранчевий — МНК, малиновий — активний вузол), світла й темна теми (`prefers-color-scheme`).
- Доступність: кнопки з `aria-pressed`, текстовий статус, керування з клавіатури.
- Інтерфейс українською.

## 1.5. Нефункціональні вимоги та обмеження

- Працює у сучасних браузерах (Chrome, Edge, Firefox) відкриттям `index.html` без сервера.
- Без залежностей у виконуваному коді; тести — вбудований `node:test` (Node ≥ 18).
- Вузли `xᵢ` попарно різні та скінченні; `m ≤ n − 1`; кількість точок у власному наборі: 2…60.
- Обчислення кривої (400 точок) для 20 вузлів — менше 10 мс; перемальовування анімації — 60 кадрів/с на типовому ПК.
- Числова стійкість: у МНК змінна `x` нормується до `t ∈ [−1; 1]`.

## 1.6. Критерії приймання

1. Для варіанта 6 усі шість графіків (5/10/20 × Лагранж/МНК) відображаються без виходу кривої за видиму область.
2. Інтерполяційний поліном проходить через усі вузли (|p(xᵢ) − yᵢ| < 10⁻⁹), форми Лагранжа та Ньютона збігаються.
3. МНК: залишки ортогональні стовпцям дизайн-матриці (‖Aᵀr‖ ≈ 0), для `m = n − 1` збігається з інтерполяцією.
4. Анімації виконуються за FR-6, FR-7; автомасштабування працює під час анімації.
5. Автотести проходять (`npm test`); у репозиторії є коміти по етапах методології та звіт.
