# 5. Тестування та порівняльний аналіз

> Файл згенеровано скриптом `tools/analysis.js` (запуск: `npm run analysis`). Не редагувати вручну.

## 5.1. Методика

- Дані: варіант 6, набори 5 ⊂ 10 ⊂ 20 точок (`src/datasets.js`).
- Опорна функція для оцінки похибки **між** вузлами — лінія тренду `y = 5.55 − 0.35·x`, за якою згенеровано точки 6…20 (припущення A1). Похибки обчислюються на сітці з 2001 точки всередині `[x₁; xₙ]`; екстраполяція — на відстані 10 % довжини інтервалу за його межами.
- МНК: ступені m = 2, 3, 4; розв'язок QR-розкладом Хаусхолдера з нормуванням x.
- «Виключи один» (LOO): по черзі видаляється внутрішній вузол, модель будується за рештою й передбачає значення у видаленому вузлі — оцінка здатності до узагальнення.
- Автотести (`npm test`) перевіряють ядро, набори даних та таймлайни анімацій; результат прогону наведено у звіті.

## 5.7. Висновки

1. **Інтерполяція Лагранжа** точно відтворює вузли, але між ними поводиться дедалі гірше: розмах полінома відносно розмаху даних — 1.00× (5 точок), 1.00× (10) та **106.92×** (20 точок): крива виходить за межі [-352.403; 363.945] при даних у діапазоні 6.7. Це **ефект Рунге**; константа Лебега зростає з 2.208 до 5889.50855, тобто малі похибки вимірювання (±0.1) підсилюються в тисячі разів.
2. **МНК** (m = 2) зберігає стабільну якість при збільшенні кількості точок: R² = 0.99814 / 0.99769 / 0.99924, RMSE між вузлами відносно тренду — 0.026 / 0.014 / 0.013, тоді як у Лагранжа — 0.042 / 0.222 / 74.408.
3. **Екстраполяція** (+10 % за межі інтервалу): похибка Лагранжа 0.169 / 30.872 / 9.54e+5 проти 0.007 / 0.014 / 0.018 у МНК (m = 2) — поліном високого ступеня для екстраполяції непридатний.
4. **Узагальнення (LOO):** RMSE Лагранжа — 0.09 / 1.033 / 571.311; МНК (m = 2) — 0.049 / 0.064 / 0.064.
5. **Ступінь m:** для майже лінійних даних підвищення m з 2 до 4 майже не зменшує SSE (для 20 точок: 0.0612 → 0.0601), але для 5 точок при m = 4 МНК перетворюється на інтерполяцію (SSE = 3.9e-30) і втрачає згладжувальну властивість.
6. **Числова стійкість:** нормування x та QR-розклад дають точність, недосяжну для нормальних рівнянь на зсунутих вузлах (див. 5.6); форми Лагранжа й Ньютона збігаються (макс. розбіжність для 20 точок — 1.63e-9, що відображає погану обумовленість задачі, а не помилку коду).
7. **Швидкодія:** побудова кривої з 400 точок — 0.03 / 0.05 / 0.29 мс (Лагранж, O(n²) на точку), що значно менше за кадр анімації (16 мс).
