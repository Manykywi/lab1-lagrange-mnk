# ЛР № 1. Апроксимація функцій: інтерполяція Лагранжа та МНК

Веб-застосунок мовою JavaScript (без бібліотек і збірки): будує інтерполяційний поліном Лагранжа та
МНК-апроксимацію за таблично заданими точками, показує залишки, анімує побудову й порівнює результати
для **5, 10 та 20 точок**. Варіант № 6. Виконавець: Белеканич Максим Олександрович, ІПЗ-1 (УжНУ).

## Запуск

Відкрийте `index.html` у браузері (Chrome / Edge / Firefox) — сервер не потрібен.

```bash
npm test            # автотести (node:test, Node ≥ 18)
npm run analysis    # порівняльний аналіз → docs/05-analysis.md
```

## Що реалізовано

| Вимога лабораторної | Де / як |
|---|---|
| Вибір набору з інтерфейсу | кнопки 5 / 10 / 20 (варіант 6) та «Власний» (форма «x y») |
| Інтерполяція Лагранжа + таблиця поділених різниць (Ньютон) | `src/math.js` (`lagrangeEval`, `dividedDifferences`), панель «Поділені різниці» |
| МНК: дизайн-матриця, стійкий метод, залишки | `designMatrix`, `solveLeastSquares` (QR Хаусхолдера), `fitPolynomial`; m = 2, 3, 4 |
| Графіки: точки, Лагранж, МНК, діаграма залишків, перемикач «Інтерполяція / МНК / Усі» | `src/chart.js`, `src/app.js` |
| Анімація інтерполяції (покрокове додавання вузлів, активний вузол) | кнопка «▶ Інтерполяція», `src/animation.js` |
| Анімація МНК (ріст полінома від ȳ, залишки відрізками) | кнопка «▶ МНК» |
| **Автомасштабування осей X та Y** (min/max функції) | `Chart.computeTarget`, `LabMath.autoScale`; працює й під час анімації |
| 6 графіків (3 Лагранж + 3 МНК) і миттєве перемикання 5/10/20 | подання «Порівняння 5·10·20» та кнопки наборів |
| Адаптивне полотно, осі, сітка, легенда, підказки, контрастні кольори | `src/chart.js`, `src/style.css` (світла/темна теми) |
| Коміт на кожний етап | `git log` — див. нижче |

Додатково: екстраполяція ±20 % (демонстрація ризиків), режим «Фокус на вузлах», порівняльна таблиця метрик.

## Методологія та історія комітів

Agile, 5 ітерацій (`docs/02-methodology.md`); кожна ітерація — окремий коміт:

0. `docs: ТЗ та вибір методології`
1. `docs: блок-схеми та таблиці ідентифікаторів`
2. `feat(core): математичне ядро та тести`
3. `feat(ui): Canvas-графіки, автомасштаб, залишки, підказки`
4. `feat(anim): анімації інтерполяції та МНК, 6 графіків і порівняння`
5. `test` / `docs`: порівняльний аналіз, діаграми взаємодії, звіт, AI-лог

## Припущення щодо даних

У таблиці варіантів для № 6 задано лише 5 точок: (1; 5.2), (2; 4.8), (3; 4.5), (4; 4.1), (5; 3.8).
Набори 10 і 20 точок — вкладені продовження тієї ж закономірності (`y ≈ 5.55 − 0.35·x` + похибка до ±0.1);
значення — у `src/datasets.js`. Якщо викладач надав інші набори для 10/20 точок — замініть масив `POINTS_20`.
